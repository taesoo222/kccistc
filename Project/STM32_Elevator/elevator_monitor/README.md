# ELV Monitor

STM32 NUCLEO-F411RE 3층 엘리베이터의 PC 감시 프로그램입니다.
보드와 USB(UART 115200)로 연결해서 층 표시, 원격 호출, 비상 정지, 비상 해제(관리자 PIN)를 합니다.
보드 없이 화면을 확인할 수 있는 데모 모드도 있습니다.

## 실행

Python 3와 Tkinter가 필요합니다.

```bash
pip install -r requirements.txt
python main.py
```

Windows에서는 `install.bat`로 패키지를 설치하고 `run.bat`로 실행할 수 있습니다.

## 보드 연결

1. 보드에 엘리베이터 펌웨어를 올리고 USB로 PC에 연결합니다.
2. 같은 COM 포트를 쓰는 다른 시리얼 프로그램을 닫습니다.
3. 프로그램을 켜면 보드 포트를 자동으로 찾습니다. 못 찾으면 왼쪽 아래에서 포트를 고르고 [연결]을 누릅니다.

보드가 없으면 [데모 모드]를 사용합니다.

| 키 | 동작 (데모 모드) |
|---|---|
| `1` `2` `3` | 층 호출 |
| `E` | 현장 비상 버튼 |
| `P` | 통신 끊기, 다시 잇기 |

## 사용법

- **원격 호출:** 3F, 2F, 1F 버튼을 누르면 해당 층으로 이동합니다.
- **비상 정지:** 프로그램의 [비상 정지] 버튼이나 보드의 비상 버튼을 누르면 정지하고 경보가 울립니다.
- **비상 해제:** [비상 해제]에서 관리자 PIN을 입력하고 현장 안전 확인에 체크하면 1층으로 돌아가 위치를 다시 맞춥니다.
- **관리자 PIN:** 처음 값은 `1234`이고, 3번 틀리면 30초 동안 잠깁니다. 바꾼 PIN은 `monitor_config.json`에 해시로 저장됩니다. 이 파일을 지우면 `1234`로 돌아갑니다.

## 통신 프로토콜

```
[0xAA] [LEN] [CMD] [PAYLOAD ...] [CKSUM]
LEN   = 1 (CMD) + PAYLOAD 길이
CKSUM = (LEN + CMD + PAYLOAD) & 0xFF
응답 CMD = 요청 CMD + 0x80
```

| CMD | 방향 | 내용 | 데이터 |
|---|---|---|---|
| `0x50` | PC에서 보드 | 층 호출 | 층 (1~3) |
| `0x51` | PC에서 보드 | 상태 요청 | 없음 |
| `0x41` | PC에서 보드 | 비상 해제 | 없음 |
| `0x43` | PC에서 보드 | 비상 정지 | 없음 |
| `0x40` | 보드에서 PC | 비상 정지 발생 (이벤트) | 층, 방향, 원인 |
| `0x42` | 보드에서 PC | 층 도착 (이벤트) | 층 |

## 파일 구성

| 파일 | 내용 |
|---|---|
| `main.py` | 시작 파일 |
| `ui.py` | 화면 |
| `link.py` | 보드 연결(`SerialLink`), 데모(`SimLink`) |
| `protocol.py` | 패킷 생성과 해석, 포트 자동 감지 |
| `settings.py` | 이름, 시간, 색, 글꼴 설정 |
| `security.py` | 관리자 PIN 저장과 확인 |
