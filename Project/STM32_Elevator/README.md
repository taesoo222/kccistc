# STM32_Elevator

STM32F411RE(NUCLEO)로 만든 3층 엘리베이터 모형입니다. 스텝모터가 실을 감고 풀어 칸을 움직이고, 포토 인터럽터 3개(외부 인터럽트)로 층을 감지합니다.

## 기능

| 기능 | 설명 |
|------|------|
| HOMING | 전원을 켜면 1층을 찾아 내려가 차단판 가운데에 멈춥니다. |
| 호출 기억 | 이동 중에도 층 버튼을 누르면 기억하고, 호출 램프(LED)가 켜집니다. |
| 운행 순서 | 가던 방향의 가장 가까운 호출부터 처리하고, 없으면 반대 방향으로 갑니다. 지나가는 층에 호출이 있으면 그 층에서 섭니다. |
| 문 열림 | 도착하면 3초 동안 문 열림 상태입니다. 멈춘 층의 버튼을 다시 누르면 문 열림 시간이 늘어납니다. |
| 상단 표시기 | 16x2 LCD에 큰 화살표(▲▼ 애니메이션)와 큰 층 숫자를 보여 주고, 도착하면 깜빡입니다. |
| 방향 자동 판별 | 실이 다 풀리면 반대로 감기므로, 센서가 걸리는 순서를 보고 "위" 모터 방향을 자동으로 뒤집습니다. |
| 안전장치 | 층 사이에서 센서가 안 걸리면(시간 초과) 또는 층을 건너뛰면 모터를 멈추고 경보음을 냅니다(ERROR). |
| 점검 운전 | ERROR 상태에서 버튼으로 모터를 직접 돌리고 다시 HOMING 할 수 있습니다. |

- 부저 소리: 전원을 켤 때, 버튼을 누를 때, 층에 도착할 때, ERROR일 때 납니다.
- UART(115200)로 센서 IN/OUT, 스텝 수, 상태/층/호출(`calls=[-23]`), 방향 뒤집힘(`DIR FLIP`) 로그를 출력합니다.

## 버튼

| 버튼 | 핀 | 평소 | ERROR (점검 운전) |
|------|----|------|-------------------|
| 1층 | PC3 | 1층 호출 | 2초 길게 누르면 다시 HOMING |
| 2층 | PC1 | 2층 호출 | 누르는 동안 모터 정방향(CW) |
| 3층 | PC0 | 3층 호출 | 누르는 동안 모터 역방향(CCW) |

## 하드웨어 연결

| 부품 | 핀 |
|------|----|
| 스텝모터 28BYJ-48 + ULN2003 (IN1~IN4) | PA0, PA1, PA4, PB0 |
| 포토 인터럽터 1F / 2F / 3F | PC10 / PC11 / PC12 (EXTI 양엣지, 외부 풀업) |
| 호출 램프 LED 1F / 2F / 3F | PB13 / PB14 / PB15 |
| I2C LCD (0x27) | I2C1: PB8 (SCL), PB9 (SDA) |
| 부저 | PA11 (TIM1_CH4 PWM) |
| UART 로그 | USART2: PA2 (TX), PA3 (RX) |

## 구조

```
Core/Src/
├── ap/            # 앱: 버튼, 램프, 효과음, UART 로그 (ap_main.c)
│   └── service/   # elevator (상태 머신, 운행), display (LCD 상단 표시기), sound
├── driver/        # StepMotor, photoSensor, button, led, lcd, buzzer
└── common/        # queue
```

- 상태: HOMING → IDLE → UP / DOWN → DOOR → IDLE, 이상 시 ERROR
- TIM9 (1ms): 스텝모터 1스텝(하프스텝). 이보다 빠르면 탈조합니다.
- EXTI15_10: 포토 인터럽터. 층 위치는 센서로만 판단하고, 센서에 들어간 뒤 250스텝(차단판 폭의 절반) 더 가서 섭니다.
- TIM1: 부저 PWM

## 빌드

이 폴더에는 `.ioc`와 직접 작성한 코드(`main.c`, `ap/`, `driver/`, `common/`)만 들어 있습니다.

1. STM32CubeIDE에서 `MINI_STM32_Elevator.ioc`로 새 프로젝트를 만들고 코드를 생성합니다.
2. 이 폴더의 `Core/Src`를 생성된 프로젝트의 `Core/Src`에 덮어씁니다.
3. 빌드합니다.
