# Icons

`rock.png` (U+270A ✊), `scissors.png` (U+270C ✌), `paper.png` (U+270B ✋) are 128x128 PNGs from
**Noto Emoji** by Google: https://github.com/googlefonts/noto-emoji (`2D/png/128/emoji_u270a.png`,
`emoji_u270c.png`, `emoji_u270b.png`), unmodified.

version 2.0", while the repository's `LICENSE` file (copied here as `LICENSE`) is the SIL Open Font
