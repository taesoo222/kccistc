# 가위바위보 게임 실행방법

라즈베리파이5 + USB 웹캠으로 하는 가위바위보 게임입니다.
2인 대전이랑 AI(컴퓨터) 대전 두 가지 모드가 있습니다.

## 파일

아래 파일들을 한 폴더에 넣어두면 됩니다.

- rps_game.py : 게임 실행 파일
- crop_hands.py : 손 부분 잘라내는 코드
- finger_rule.py : 손가락 개수로 판정 보조
- rps_model.tflite : 학습시킨 모델
- icons/ : 화면에 나오는 가위바위보 이미지
- requirements.txt

## 설치

처음 한 번만 하면 됩니다.

```
cd rps_game
python3 -m venv env
source env/bin/activate
pip install -r requirements.txt
```

## 실행

```
cd rps_game
source env/bin/activate
python rps_game.py
```

MobaXterm 같은 걸로 원격 접속해서 실행하는데 파이 모니터에 띄우고 싶으면
`DISPLAY=:0 python rps_game.py` 로 실행하면 됩니다.

## 게임 방법

1. 실행하면 메뉴가 나옵니다. 1번 누르면 2인 대전, 2번 누르면 AI 대전입니다.
   (키가 안 먹히면 게임 창을 한 번 클릭하고 누르면 됩니다)
2. 2인 대전은 화면 왼쪽이 P1, 오른쪽이 P2입니다.
3. 카메라에 손을 보이면 박스가 생기는데, 회색 박스면 손이 화면 끝에 걸린 거라 안쪽으로 옮겨야 합니다.
4. 스페이스바를 누르면 3, 2, 1 카운트가 나오고 SHOW! 가 뜰 때 가위바위보를 내면 됩니다.
5. 결과가 나오고 오른쪽에 서로 낸 것이랑 점수가 나옵니다.
6. 스페이스바로 다음 판 진행하고, 먼저 2번 이기면 최종 승리입니다.
   최종 승리 화면에서 스페이스바 누르면 새 게임이 시작됩니다.

키 정리
- 1 / 2 : 모드 선택 (메뉴)
- 스페이스바 : 시작 / 다음 판
- b : 메뉴로
- r : 점수 초기화
- q 또는 ESC : 종료

## 참고

- 카메라가 안 열리면 웹캠이 제대로 꽂혀 있는지, 다른 프로그램에서 카메라를 쓰고 있지 않은지 확인하면 됩니다.
  카메라 번호가 다르면 `python rps_game.py --camera 1` 처럼 번호를 바꿔서 실행합니다.
- 가위바위보 이미지 대신 도형이 나오면 icons 폴더가 같은 위치에 있는지 확인하면 됩니다.
