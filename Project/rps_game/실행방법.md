# 실행방법 - 웹캠 가위바위보 게임

## 1. 준비물

- Raspberry Pi 5 + USB 웹캠 (파이에 꽂아 두기)
- 파이 화면 (모니터 연결 또는 MobaXterm 등 원격 화면)

## 2. 파일 넣기

압축을 풀고 폴더를 파이에 그대로 복사합니다. 아래 파일들이 **한 폴더 안에** 있어야 합니다.

```
rps_game/
├── rps_game.py         ← 실행할 파일
├── crop_hands.py
├── finger_rule.py
├── rps_model.tflite    ← 학습한 모델
├── icons/              ← 이모지 이미지 3개
└── requirements.txt
```

## 3. 설치 (처음 한 번만)

터미널에서 폴더로 이동한 뒤 입력합니다.

```bash
cd rps_game
python3 -m venv env
source env/bin/activate
pip install -r requirements.txt
```

## 4. 실행

```bash
cd rps_game
source env/bin/activate
python rps_game.py
```

원격 접속 중인데 창을 파이 모니터에 띄우고 싶으면: `DISPLAY=:0 python rps_game.py`

## 5. 게임 방법

1. 실행하면 **시작 메뉴**가 나옵니다. (키를 누르기 전에 게임 창을 한 번 클릭해 주세요)
   - `1` : **2인 대전** (화면 왼쪽 사람 = P1, 오른쪽 사람 = P2)
   - `2` : **AI 대전** (나 vs 컴퓨터)
2. 카메라에 손을 보여 주면 손에 박스가 생깁니다.
   - 박스가 **회색**이면 손이 화면 가장자리에 있는 것이니 안쪽으로 옮겨 주세요.
3. `SPACE` 를 누르면 **3 - 2 - 1** 카운트가 나옵니다.
4. **SHOW!** 가 나올 때 가위 / 바위 / 보를 냅니다.
5. 화면에 결과(WIN / LOSE / DRAW)가 나오고, 오른쪽에 양쪽이 낸 것과 점수가 표시됩니다.
6. 다시 `SPACE` 를 눌러 다음 판을 합니다. **먼저 2승** 하면 매치 승리 화면이 나옵니다.
   - 매치 승리 화면에서 `SPACE` : 새 매치 시작

### 키 정리

| 키 | 동작 |
|---|---|
| `1` / `2` | (메뉴에서) 2인 대전 / AI 대전 선택 |
| `SPACE` | 게임 시작 / 다음 판 / 새 매치 |
| `b` | 메뉴로 돌아가기 |
| `r` | 점수 초기화 |
| `q` 또는 `ESC` | 종료 |

## 6. 안 될 때

| 증상 | 해결 |
|---|---|
| `카메라 0번을 열 수 없습니다` | 웹캠 연결 확인, 다른 프로그램이 카메라를 쓰고 있으면 끄기. 그래도 안 되면 `python rps_game.py --camera 1` |
| 창이 안 뜸 | 원격 접속이면 `DISPLAY=:0 python rps_game.py` 로 파이 모니터에 띄우기 |
| 키를 눌러도 반응 없음 | 게임 창을 한 번 클릭한 뒤 다시 누르기 |
| 이모지 대신 도형이 보임 | `icons` 폴더가 `rps_game.py` 와 같은 폴더에 있는지 확인 |
