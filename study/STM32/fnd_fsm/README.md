# FND Stopwatch FSM (STM32)

## Overview

A 4-digit 7-segment (FND) counter on an **STM32F411RE** (100 MHz from an
8 MHz HSE), written in C with the STM32 HAL. Two buttons drive a three-state
FSM: start/stop counting and clear. The counter goes up by 1 every 100 ms
(0.1 s per count) and wraps from 9999 to 0.

## Project Structure

```
fnd_fsm/
├── 20261014_FND_fsm.ioc        # STM32CubeMX configuration (MCU, clock, pins)
└── Core/Src/
    ├── main.c                  # Button edge detection + STOP/RUN/CLEAR FSM
    └── driver/fnd/
        ├── fnd.h               # fnd_show_number() declaration
        └── fnd.c               # 4-digit multiplexing and segment patterns
```

Only hand-written code and the `.ioc` file are kept. Everything else is
generated by STM32CubeIDE and is not tracked: HAL/CMSIS drivers, startup
file, `system_stm32f4xx.c`, `stm32f4xx_it.c`, `stm32f4xx_hal_msp.c`,
`syscalls.c`, `sysmem.c`, headers in `Core/Inc/`, linker scripts, IDE
settings, and the `Debug/` build output.

## Architecture

| State | Button 1 (run/stop) | Button 2 (clear) | Action |
|---|---|---|---|
| `STOP` | → `RUN` | → `CLEAR` | Hold the current value |
| `RUN` | → `STOP` | — | +1 every 100 ms (`HAL_GetTick()`), 9999 → 0 |
| `CLEAR` | — | — | Reset to 0, then → `STOP` on the next loop |

- **Main loop**: each pass calls `update_buttons()` and then the current
  state's function. All three state functions end with `fnd_show_number()`.
- **Buttons**: active-low. A press is detected on the 1 → 0 edge between two
  loop passes. There is no debounce filter.
- **FND driver** (`fnd.c`): each `fnd_show_number()` call turns all digits
  off, outputs one digit's segment pattern, selects that digit, and waits
  1 ms (`HAL_Delay(1)`). Four calls cover all four digits, so the display
  refreshes every ~4 ms (~250 Hz). This 1 ms delay also sets the main-loop
  period.

## Pin Map

| Function | Pin | Level |
|---|---|---|
| Button 1 (run/stop) | PC0 | Input, low = pressed |
| Button 2 (clear) | PC1 | Input, low = pressed |
| Digit 1–4 select | PA5, PB6, PC7, PA10 | Output, low = selected |
| Segments A–G, DP | PA6, PA9, PB5, PB10, PA8, PA7, PB3, PB4 | Output, high = on |

Digit 1 is the thousands digit; digit 4 is the ones digit.

## How to Build

1. In STM32CubeIDE, create a project from `20261014_FND_fsm.ioc`
   (*File → New → STM32 Project from an Existing STM32CubeMX Configuration File*),
   or open the `.ioc` in an existing project.
2. Run *Project → Generate Code*.
3. Replace the generated `Core/Src/main.c` with the one here, and copy
   `Core/Src/driver/` into the project.
4. Build and flash.
